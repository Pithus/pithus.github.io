The comparison page is used to compare two analysis reports side by side, especially useful to distinguish two very similar sample appart.

To run a comparison, input the first sample sha256 to the left input bar, and the second sample's sha256 to the right input bar then click the magnifier icon.
Both reports will be displayed side by side.
