# Report header

The report header gives a quick summary of the information reported through the analysis.

![report header](/src/assets/doc/reportheader.png)

## APK name

In the top middle of the screen are shown the name and package name of the analyzed APK file. Right underneath is the date of the analysis.

## Threat summary

On the top left side of the screen is the estimated threat level. This data is computed by VirusTotal, MalwareBazaar and Quark-Engine. When malicious samples are detected, it is clearly displayed, with the number of anti-virus flagging it. The threat summary also displays the most probable threat name.

## Action buttons

Under the threat summary are for buttons, they are only available when logged in to the instance. They allow multiple actions, from left to right:
- download sample: allows the user to download the original APK that was submitted for this analysis.
- export to JSON: get a JSON object containing all the report information, this can also be obtained through the API.
- [bookmark](/reference/interface/workspace#bookmarks): allows to bookmark the sample, it will then show up in your workspace.
- [comparison](/reference/interface/comparison): allows to compare the current report to another sample's report using their sha256 hash.

## Report stats

At the bottom, five cards display quick stats about the sample, from left to right:
- Permissions: the number of permissions the application declares and asks for.
- Activities: the number of activities declared by the application.
- Services: the number of services declared by the application.
- Receivers: the number of receivers declared by the application.
- Domains: the number of domain names found in the application code, those are some of the network endpoints the application communicates with.
