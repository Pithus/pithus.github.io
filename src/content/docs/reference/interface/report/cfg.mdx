The Control Flow Analysis allows to visualize interesting parts of the code through a graphical representation of the code along with the code itself.
The magnifier icon on the right of the Java Class name allows to pivot to a similarity search of that specific class.

Clicking on the name of the Java Class shows the code:

![code](/src/assets/doc/cfgcode.png)

While clicking on the picture on the right makes it more readable:

![graph](/src/assets/doc/cfggraph.png)
